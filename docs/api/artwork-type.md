# Artwork Type System

## Overview

Every artwork on ArtCurve has a **type** that declares how it was created. This is a self-reported declaration by the creator at upload time in the Studio.

## Types

| Type | Value | Description |
|------|-------|-------------|
| Original | `ORIGINAL` | Hand-made artwork — painting, drawing, digital art, photography, etc. |
| AI Generated | `AI_GENERATED` | Fully generated by AI tools (Midjourney, DALL-E, Stable Diffusion, etc.) |
| AI Assisted | `AI_ASSISTED` | Human-created with AI assistance (AI used as a tool, not the sole creator) |

## How It Works

### Creator Declaration (Studio)

When creating an artwork in the Studio (`POST /artworks`), the creator selects the artwork type from a dropdown. The field `artwork_type` is included in the creation payload:

```json
{
  "title": "Nocturne at the Bridge",
  "description": "...",
  "category": "Digital",
  "artwork_type": "ORIGINAL",
  "supply": 10000,
  "init_price": 0.001,
  "curve_type": "quadratic"
}
```

The type cannot be changed after creation.

### Marketplace Filtering

Users can filter artworks by type on the marketplace:

```
GET /api/v1/artworks?artwork_type=ORIGINAL
GET /api/v1/artworks?artwork_type=AI_GENERATED
GET /api/v1/artworks/search?artwork_type=ORIGINAL&q=sunset
```

On the frontend, artwork type appears as color-coded chips:
- **Green** — ORIGINAL
- **Purple** — AI_GENERATED / AI_ASSISTED

### Database

The `artworks` table includes an enum column:

```sql
CREATE TYPE artwork_type AS ENUM ('ORIGINAL', 'AI_GENERATED', 'AI_ASSISTED');

ALTER TABLE artworks ADD COLUMN artwork_type artwork_type NOT NULL DEFAULT 'ORIGINAL';
```

The column was added via a TypeORM migration. Default is `ORIGINAL` for backward compatibility with artworks created before the type system was introduced.

### Trade Page

The artwork type badge is displayed on the trade terminal next to the artwork title, so traders can see at a glance whether they're trading shares of an original or AI-generated piece.
